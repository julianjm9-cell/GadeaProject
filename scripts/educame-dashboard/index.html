    1. Crea un token de acceso limitado y selecciona el repositorio de Educame.

    Cómo preparar el acceso al VPS
      
          
    1. Autoriza en Hostinger la clave pública SSH de este equipo para un usuario con acceso a la instalación y a Docker.
      2. 
          
    2. Conéctate una vez desde PowerShell con ssh usuario@servidor y verifica la identidad del VPS con el proveedor.
      3. 
          
    3. Introduce aquí ese destino o su alias de OpenSSH y pulsa Probar conexión.
      4.

      Cómo conectar Runway
        
            
      1. En el portal de desarrolladores de Runway, crea una clave API para tu cuenta.

        3.

      Cómo configurar Google Search Console
            
      1. Habilita Search Console API en Google Cloud.
      2. Crea un cliente OAuth de tipo Aplicación web y registra la URL de retorno que aparece aquí.
      3. Pega el ID y el secreto y autoriza con una cuenta que tenga acceso a la propiedad.
      
            
            
            
      Si el proyecto está en pruebas, añade tu cuenta de Google como usuario de prueba.
