    Solicitudes de cambios

    Cómo conectar GitHub
    1. Crea un token de acceso limitado y selecciona el repositorio de Educame.
    2. Concede lectura de Checks y lectura y escritura de Contents y Pull requests.
    3. Pega el token aquí y pulsa Conectar. Después podrás revisar los archivos y las pruebas de cada propuesta.

    Despliegue en Hostinger

    Hostinger sin verificar.

    Cómo preparar el acceso al VPS
    1. Autoriza en Hostinger la clave pública SSH de este equipo para un usuario con acceso a la instalación y a Docker.
    2. Conéctate una vez desde PowerShell con ssh usuario@servidor y verifica la identidad del VPS con el proveedor.
    3. Introduce aquí ese destino o su alias de OpenSSH y pulsa Probar conexión.

    También puedes copiar el comando de la revisión desde Cambios y pegarlo en la consola de Hostinger.

      Cómo elegir el motor

      Guarda una clave y elige OpenAI API y un modelo en el chat o en el encargo. El consumo se factura en tu cuenta API, separado de Codex. Cada pasada tiene un límite de 24 pasos o 120.000 tokens; las implementaciones incluyen una segunda pasada de revisión. Si falla, conserva la copia y el motor elegido.

      Claude API

      Para automatizar encargos en la cola. Usa una clave de Claude Console de un solo espacio de trabajo y su facturación API.

      Obtener clave ↗

      Cómo conectar Claude
      1. Crea una clave API en tu cuenta de Anthropic con saldo disponible.
      2. Guárdala aquí y elige Claude API en el chat o en un encargo.
      3. Selecciona uno de los modelos que devuelve tu cuenta.

      La API tiene facturación propia. Cada pasada admite hasta 24 pasos o 120.000 tokens. Las implementaciones incluyen revisión. Copiador usa los motores con búsqueda disponibles; Claude no abre enlaces en esta versión.

      Consumo API en este equipo

      Sin llamadas registradas.

      Tokens informados por cada proveedor. No equivalen a saldo ni incluyen llamadas de otras herramientas. Consulta la facturación del proveedor para conocer el coste.
