# Juegos avanzados públicos propuestos

Una propuesta por cada combinación de curso y asignatura que figura en el temario actual de Profesor Particular: 55 juegos escolares. Español se organiza por nivel lingüístico, por eso se añaden seis juegos A1–C2. Total: **61 juegos**.

Cada fila indica el tema curricular que sirve de base, un título pensado para la biblioteca pública, el tipo de juego avanzado disponible en el creador y una mecánica concreta. Los cuatro juegos de 1.º Primaria ya están implementados en la biblioteca pública; los otros 57 siguen siendo propuestas. Antes de publicar cada nuevo juego conviene revisar manualmente todas las preguntas, respuestas, pistas y explicaciones.

## Criterios para convertirlos en materiales públicos

- Un único tipo de juego por material, con suficientes rondas para que resulte divertido y una duración aproximada de 5–8 minutos.
- Enunciados, pistas y respuestas adecuados a la edad. La ambientación debe ayudar a entender el reto, sin esconder la explicación curricular.
- Soluciones inequívocas, revisión humana de datos y fechas, y una explicación breve para cada respuesta dudosa.
- Miniatura infantil para Primaria y versión visual adolescente para ESO/Bachillerato, usando el sistema de imágenes que ya existe.
- Etiquetas exactas de curso, asignatura y tema para que los filtros de la biblioteca pública funcionen.
