# Conceptos clave

## API

Una API es una forma de comunicacion entre programas. Por ejemplo, una app de facturacion puede pedir datos de clientes a un backend usando una API.

- Categoria: Backend
- Nivel: Basico
- Estado: Pendiente de practicar
- Ejemplo empresarial: CRM que consulta la lista de clientes
- Relacionado con: HTTP, JSON, endpoints, backend

## Base de datos

Una base de datos sirve para guardar informacion estructurada: clientes, productos, facturas, usuarios, pedidos o tareas.

- Categoria: Datos
- Nivel: Basico
- Estado: Pendiente de practicar
- Ejemplo empresarial: sistema de inventario
- Relacionado con: SQL, tablas, registros, consultas

## Dashboard

Un dashboard es una pantalla con metricas importantes para una empresa.

- Categoria: Producto empresarial
- Nivel: Intermedio
- Estado: Pendiente
- Ejemplo empresarial: ventas del mes, clientes nuevos, facturas pendientes
- Relacionado con: graficos, KPIs, filtros, reportes

## CRM

Un CRM es una aplicacion para gestionar clientes, contactos, oportunidades, llamadas, tareas comerciales y ventas.

- Categoria: App empresarial
- Nivel: Intermedio
- Estado: Pendiente
- Ejemplo empresarial: panel para comerciales
- Relacionado con: clientes, ventas, pipeline, tareas

# Errores y soluciones

## Plantilla de error

### Error

Nombre o mensaje del error.

### Donde paso

Proyecto, archivo o parte de la app.

### Causa

Explicacion simple.

### Solucion

Pasos para arreglarlo.

### Como evitarlo

Regla o aprendizaje para la proxima vez.

## Ejemplo - ModuleNotFoundError

### Error

`ModuleNotFoundError`

### Donde paso

Al ejecutar un proyecto de Python.

### Causa

Python no encuentra una libreria necesaria.

### Solucion

Instalar la libreria con:

```bash
pip install nombre_libreria
```

### Como evitarlo

Guardar las dependencias del proyecto en un archivo `requirements.txt`.

# Glosario

## Frontend

Parte visible de una aplicacion: pantallas, botones, formularios y tablas.

## Backend

Parte interna que procesa datos, conecta con la base de datos y expone APIs.

## Deploy

Subir una aplicacion para que otras personas puedan usarla desde internet.

## CRUD

Crear, leer, actualizar y eliminar datos.

## Endpoint

URL de una API que permite hacer una accion concreta.

## KPI

Indicador importante para medir el rendimiento de una empresa.
