👁Modo visión — un solo paso

En modo visión el modelo ve la imagen directamente y extrae todos los campos en una sola llamada, sin OCR previo. Más preciso para facturas escaneadas o fotografías. Requiere un modelo con soporte de imágenes: qwen3-vl, llama3.2-vision o GPT.

Visión Ollama local
Usa el modelo de análisis seleccionado viendo la imagen directamente. Actívalo si tienes qwen3-vl u otro modelo multimodal.
Visión GPT API
GPT recibe la imagen directamente. Úsalo solo si el OCR local falla o la factura viene escaneada/fotografiada.
